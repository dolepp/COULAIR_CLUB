# Подключение официального СДЭК API v2

Магазин подготовлен к авторизации OAuth, поиску городов, получению ПВЗ/постаматов и расчёту тарифов 136/368. Город отправки — 251 (Нижний Тагил). К рассчитанной доставке применяется скидка 50% от двух единиц товара. Наценка и фиксированные цены остаются настройками магазина.

Ключи получают в [личном кабинете СДЭК](https://lk.cdek.ru/integration/index). [Официальная документация](https://apidoc.cdek.ru/), [инструкция подключения](https://www.cdek.ru/ru/integration/).

На сервере магазина закрытый файл `/var/lib/coulair-api/cdek-credentials.json` (владелец `coulair`, права `600`):

```json
{"client_id": "идентификатор из ЛК", "client_secret": "секрет из ЛК"}
```

Заполнять через редактор на сервере; не передавать секреты параметрами команд, в Git или в переписке. `.env` уже должен содержать `CDEK_ENV=production`, `CDEK_CREDENTIALS_FILE=/var/lib/coulair-api/cdek-credentials.json`, `CDEK_CALC=auto`, `CDEK_FALLBACK_CALC=lk`.

Проверка из `/opt/coulair-api`:

```sh
sudo -u coulair node --env-file=.env cdek-check.js --configuration
sudo -u coulair node --env-file=.env cdek-check.js --tariffs --city 250
```

Код завершения: 0 — проверка прошла, 2 — ключи ещё не заполнены/некорректна конфигурация, 1 — ошибка проверки API. Команды не создают отправлений и не выводят ключи или токены. Общий учебный контур проверяется отдельно: `node --env-file=.env cdek-check.js --sandbox --tariffs --city 250`; его цены не используются при покупке на сайте.

После успешной проверки боевых ключей: `sudo systemctl restart coulair-api`. В `/api/health` поле `cdekApi.apiActive` должно стать `true`, `calculator` — `api`. `authenticated` подтверждает актуальный токен текущего процесса после первого запроса API; отдельная команда проверки имеет собственный кеш токена.

Пока ключи пустые, режим `auto` сохраняет действующий калькулятор сайта СДЭК. Заполнение ключей и перезапуск переключают на официальный API. Ошибочный JSON или неполная пара ключей отражаются в диагностике, резервный расчёт продолжает работать. Явный режим `api` блокирует расчёт без боевых ключей; учебные цены не подставляются.

Сохранены старые имена `CDEK_ACCOUNT`/`CDEK_SECURE`, поддержаны новые `CDEK_CLIENT_ID`/`CDEK_CLIENT_SECRET`. Переменные окружения имеют приоритет над файлом. Параллельные запросы используют один запрос токена; токен обновляется до истечения срока и однократно после 401. Ошибки не содержат секретов. Автоматическая регистрация посылок не включена.
