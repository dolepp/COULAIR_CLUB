# coulair-api

Node.js API магазина: города и пункты СДЭК, расчёт доставки (таблица «расстояние от Нижнего Тагила × вес»
или калькулятор СДЭК), оплата ЮKassa, заявки в Telegram, письма клиентам.

На сервере:
- код — `/opt/coulair-api` (`npm ci --omit=dev`), настройки — `/opt/coulair-api/.env` (образец `.env.example`, права 600);
- служба — `coulair-api.service` (порт 3100), заказы — `/var/lib/coulair-api/orders/*.json`;
- nginx — `nginx-coulair.conf`: сайт из `/var/www/coulair/current` (ссылка на `releases/<версия>`), `/api/` → 3100.

Уведомления ЮKassa: `https://coulair.ru/api/yookassa/webhook` (payment.succeeded, payment.canceled).

Остатки и продажи Google Sheets:
- `SHEETS_ID` — таблица учёта; `SHEETS_TOKEN_FILE` — отдельный закрытый OAuth-файл, доступный пользователю службы.
- «Партии»: A — партия, B — размер, C — поступление, D — продажи, E — остаток. D/E считаются формулами по «Заказам»; отменённые и возвращённые строки не списываются.
- `GET /api/stock` возвращает только доступные количества по размерам, без заказов и персональных данных. Обновление страницы каждые 30 секунд, кеш API до 15 секунд; перед резервом всегда свежее чтение.
- Новые заказы резервируют партию до оплаты/подтверждённой отмены. Оплаченные записываются поштучно в «Заказы», колонка P содержит уникальный ключ сайта. Повторная доставка webhook не списывает товар повторно. Существующие заказы до подключения автоматически не импортируются.
- При недоступности Google новые покупки штанов блокируются. Уже оплаченные заказы сохраняются локально и повторяют запись раз в минуту; оплаченный товар остаётся зарезервирован до успешной записи.
- Себестоимость/прибыль в H автоматически считается для штанов. Для других товаров прибыль оставляется пустой: их себестоимость в таблице не задана.

Партии и цвета (13.11.2026): на листе «Партии» G — цвет (`черный`/`белый`), H — текст срока отправки, I — предзаказ (`TRUE`/`FALSE`). Партии выбираются по номеру: сначала 1, затем 2, отдельно для цвета и размера. Первая партия — «в течение 10 рабочих дней», вторая — «12–16 рабочих дней», предзаказ. В «Заказах» O хранит цвет, Q — обещанный срок каждой пары. В корзине позиции разных цветов не объединяются. В расчёте и подтверждении заказа показываются сроки каждой группы; если условия изменились между расчётом и оплатой, покупатель получает новый расчёт и подтверждает его повторно.

Доставка с 13.11.2026: от двух единиц товара действует скидка 50% на рассчитанную доставку. `deliveryDiscountFrom: 2`, `deliveryDiscountPercent: 50` в CONFIG. Сервер возвращает полную `cost` и льготную `customerCost` в расчёте каждого способа доставки, сохраняет обе суммы в заказе и передаёт в оплату и чек именно `customerCost`. Промокоды применяются после расчёта скидки на доставку. Старая акция бесплатной доставки отключена. Изменение условий доставки меняет availabilityKey: покупатель со старым расчётом должен подтвердить новый итог.

Официальный СДЭК API подготовлен: [подключение и проверка](CDEK_SETUP.md). Ключи читаются из отдельного файла или переменных, токен обновляется автоматически; учебные цены не попадают в боевую оплату. До добавления ключей `CDEK_CALC=auto` использует действующий калькулятор `lk`. Диагностика: `node --env-file=.env cdek-check.js --configuration`; затем проверка без создания посылок — `node --env-file=.env cdek-check.js --tariffs --city 250`.
